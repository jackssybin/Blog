## 核心特色

### 1. 全栈可部署到 Cloudflare 免费额度

这个项目最巧妙的地方是架构：

- 前端：Next.js 静态页面，可以部署到 Cloudflare Pages
- API：Cloudflare Workers 处理解析请求
- 音频提取：FFmpeg.wasm **完全在浏览器端处理**，不消耗后端资源
- 打包下载：JSZip 在浏览器端打包，也不用后端参与

所以整站跑下来，**个人使用完全用不完 Cloudflare 的免费额度**，真正做到零成本。

### 2. 解决了几个真实痛点

- **抖音无水印**：实测可用，解析分享口令就能拿到原视频
- **小红书原图**：单图多图都能下，保存的是原图质量
- **音频提取**：想把 B 站视频转成音频播客？浏览器直接处理，不用传文件
- **图文打包**：小红书多图笔记，可以打包成 ZIP 一次性下载

### 3. 使用体验不错

- 界面现代干净，用的 shadcn/ui + Tailwind，看着舒服
- 自动识别链接，粘贴进去自动判断平台，不用你选
- 浏览器本地保存下载历史，刷新页面还能看到
- 多语言支持，中文英文日文都有

## 5 分钟部署步骤

其实作者已经写得很清楚了，我整理一下关键步骤，照着做就能成：

### 前置要求

- Cloudflare 账号（免费即可）
- Node.js 20+，pnpm 包管理器

### 部署流程

```bash
# 1. Fork 项目后克隆到本地
git clone https://github.com/你的用户名/galaxy-downloader.git
cd galaxy-downloader

# 2. 安装依赖
pnpm install

# 3. 本地测试（可选）
pnpm dev
# 访问 http://localhost:3010 测试没问题再部署

# 4. 构建并部署
pnpm build
pnpm deploy
```

按照命令行提示登录 Cloudflare，等待几分钟就部署好了。

### 可选：配置环境变量让 SEO 更友好

**变量名** | **说明**
---|---
`NEXT_PUBLIC_SITE_URL` | 你的站点地址
`NEXT_PUBLIC_API_BASE_URL` | API 地址
`SEO_INDEXABLE` | `true` 允许索引

在 Cloudflare Workers 控制台的「设置 → 环境变量」里添加即可。
