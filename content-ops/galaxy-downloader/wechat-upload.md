## 5 分钟一键部署教程 📝

我把步骤给你整理好了，照着做就能成，真的不难：

### 准备工作
- 一个 Cloudflare 账号（免费注册就行）
- 本地装了 Node.js 20+ 和 pnpm

### 开始部署

**1️⃣ Fork 项目**
先去 GitHub 点个 Fork：
```
https://github.com/lxw15337674/galaxy-downloader
```

**2️⃣ 克隆安装**
```bash
git clone https://github.com/你的用户名/galaxy-downloader.git
cd galaxy-downloader
pnpm install
```

**3️⃣ 本地测试（可选）**
```bash
pnpm dev
```
打开 `http://localhost:3010`，试几个链接没问题再部署。

**4️⃣ 一键部署**
```bash
pnpm build
pnpm deploy
```
跟着命令行提示走，登录 Cloudflare，等几分钟就好了。

就这四步，真·5 分钟上线🚀

## 哪些坑需要注意？⚠️

实话实说，它不是完美的，我把踩过的坑告诉你：

1. **音频提取吃浏览器性能**
因为是在浏览器里用 FFmpeg 处理，太长的视频会有点慢，10 分钟以内没问题，太长的建议用桌面工具。

2. **免费额度够用吗？**
Cloudflare 免费额度每天 10 万请求，**你自己用肯定用不完**，除非你分享给几百个人同时用才会超。

3. **谁适合折腾，谁再等等？**

✅ **非常推荐你折腾**：
- 经常需要下载媒体内容
- 讨厌广告水印和收费套路
- 会点基本命令行
- 在意隐私保护

❌ **不建议折腾**：
- 完全不会代码，git 是什么都不知道
- 就下载一次，用完就走
- 需要经常下 GB 级大文件
