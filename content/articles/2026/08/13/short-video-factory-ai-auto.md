# 短视频工厂：输入提示词，AI一键自动生成短视频

上周我找AI剪辑工具的时候，又被剪映的会员弹窗劝退了——想剪一条1分钟以上的产品营销视频，要么强制水印，要么逼着开月会员。

这次我找到一款国人开源的桌面工具「短视频工厂」，输入提示词就能AI自动生成短视频，文案、配音、剪辑、字幕一条龙，完全本地运行不用上传素材，一分钱不用花。

这篇讲清楚：1）它到底能做什么，适合谁用；2）5分钟上手使用的完整流程；3）实测下来发现的优势和需要注意的坑。

## 它解决了什么痛点？

做短视频这件事，对普通人太不友好了：

- 不会剪辑：想做一条产品营销视频，得学PR剪映，太费时间
- 成本太高：平台剪辑工具基本功能免费，导出高清或者去水印就要会员
- 隐私顾虑：把产品素材上传到云端剪辑，担心商业信息泄露
- 批量难做：想做多条泛内容视频，每条都要手动剪一遍，效率太低

短视频工厂就是来解决这些问题的。它是一个开源的桌面端应用，核心思路是：**给AI提示词+素材，它帮你自动完成文案生成、语音合成、视频剪辑、字幕添加全流程**。

## 核心功能一览

项目目前已经实现了完整的短视频生成流程，主要功能包括：

- **AI文案生成**：基于你的提示词，自动生成短视频口播文案，兼容 OpenAI 接口格式，可以对接任何兼容的API
- **语音合成**：内置 EdgeTTS，免费生成自然流畅的语音，不需要额外付费
- **自动剪辑**：根据文案时长，自动拼接你的素材视频，加上转场，合成输出最终视频
- **自动字幕**：根据语音生成字幕，自动匹配时间轴叠加到视频上
- **批量处理**：支持配置批量任务，按预设自动持续合成视频，适合做泛内容账号
- **完全本地**：所有流程都在你的电脑上运行，素材不会上传到第三方服务器
- **跨平台**：支持 Windows、macOS、Linux 三大系统，下载就能用

项目路线图显示，后续还会添加更多语音合成API、更丰富的字幕特效和参数调整功能。

## 5分钟上手实测

使用非常简单，我以macOS为例，三步就能生成第一条视频：

### 第一步：下载安装

直接去 GitHub Release 页面下载对应系统的最新版本：

> https://github.com/YILS-LIN/short-video-factory/releases

解压后打开就能用，不需要安装，绿色便携。

### 第二步：配置API

打开设置，填入你的 OpenAI API Key 和 API 地址：

- 如果你用官方 OpenAI，直接填 `https://api.openai.com/v1` 和你的 Key
- 如果你用国内代理或者兼容接口，改成对应的地址就行

项目本身不收费，API 费用由你的 OpenAI 账户直接结算，成本很低——生成一条短视频的文案，token 消耗一般在几百以内，几分钱人民币。

### 第三步：创建任务生成视频

1. 新建项目，输入你的提示词，比如「介绍一款开源的AI自动短视频工具」
2. 上传你的视频素材（至少1条，多条更好，AI会自动拼接）
3. 点击生成，等待几分钟
4. 搞定！直接导出 MP4 视频

整个流程就是这么简单，不需要你懂剪辑，不需要你找配音，所有事情AI帮你做完。

## 适合哪些人用？

根据我的实测，这些场景用它会非常顺手：

✅ **推荐使用**：
- 小商家做产品营销短视频，不会剪辑不想花大钱
- 做泛内容账号（语录、情感、知识口播），需要批量产出视频

- 对隐私敏感，不想把商业素材上传到云端

❌ **不适合**：
- 需要精细剪辑复杂视频（专业剪辑还是得用PR/FCP）
- 没有 OpenAI API Key 也不想找替代接口
- 完全零电脑基础，连解压打开都觉得麻烦

## 优势和坑点总结

### 优势

1. **真免费**：项目本身MIT协议开源，没有功能限制，没有强制水印，EdgeTTS免费不用钱，只有API调用费给OpenAI，比按月订阅SaaS便宜太多
2. **真本地**：所有素材和处理都在你自己电脑上，商业项目不用担心泄露
3. **够简单**：新手不用学，三步生成，对非专业用户太友好了
4. **能批量**：配置好任务自动一直生成，做内容效率提升很多

### 需要注意的坑

1. **视频素材需要你自己准备**：AI做的是剪辑和合成，不会帮你生成素材视频，得自己准备好原素材
2. **目前字幕样式还比较基础**：作者说后续会更新更多字幕特效，现阶段够用但不够花哨
3. **第一次生成需要下载模型**：国内网络可能有点慢，耐心等一下就好
